> 状态：**已拍板 (Accepted)**

## 1. 核心战略定调 (Strategic Decisions)

经由 `/grill-with-docs` 盘问对齐，本项目锁定以下四大核心基准：

| 决策维度 | 拍板结论 | 实施准则 |
|---|---|---|
| **1. 业务定位** | **离线极速听写工具 (MVP)** | 主打 200x~300x 超高实时比与极低显存常驻，对标 CapsWriter-Offline。首版 CER 容忍度设为 **10%~15%**。 |
| **2. 功能边界** | **ASR 唯一主线，剥离 RAG** | 原版的向量搜索/RAG 功能暂不作为主线开发，归入后续特性分支。当前 100% 精力聚焦在中文语音识别上。 |
| **3. 文本策略** | **声学 MVP 纯净模式** | 不做复杂的 ITN (反向文本标准化) 与在线标点模型。第一阶段只做基础文本规范化（繁简统一、标点剥离、基础读音对齐），以最小代价跑通 CER。 |
| **4. 算力归属** | **本地 RTX 4080 Laptop (12GB) 单卡闭环** | 零云端依赖。训练参数适配 12GB 显存约束：短音频切片 (10~15s)、`max_batch_seconds=250`、梯度累积代替大 Batch。 |

## 2. 演进路线图 (Roadmap)

```
[Phase 0] 生死探针实验 (零训练，确认冻结 Conformer 对中文语音具备语义区分度)
   │
   ▼
[Phase 1] 中文文本流清洗 & Units 词表构建 (剥离越南语，适配 Gemma 262k 词表)
   │
   ▼
[Phase 2] AISHELL-1 (178h) 跑通 4080 本地训练闭环，输出首版权重与真实 CER 报告
   │
   ▼
[Phase 3] 评估同音字瓶颈，按需挂载轻量语言模型 (KenLM / N-gram) 重打分
```

## 3. 资产与分支规范

- **Git 分支**：在当前仓库拉出独立分支 `zh`，彻底清空越南语特化代码，保留 `main` 作为上游比对基准。
- **本地权重**：直接读取 `models/google/embeddinggemma-2` 原版 safetensors。
